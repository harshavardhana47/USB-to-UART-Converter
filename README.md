USB Type-C to UART Converter (CP2102)

Designed a USB Type-C to UART converter using the CP2102 in KiCad for reliable serial communication with embedded systems.

⚡ Integrated USB Type-C interface with proper CC configuration
🔄 Used CP2102 USB-to-UART bridge for TX/RX communication
🔧 Included decoupling capacitors and status LEDs for stability and debugging
📤 Exposed TX, RX, VBUS, GND pins for easy external interfacing
✅ ERC verified (0 errors) ensuring schematic reliability
